## Description

A simple CRUD console app that fetches data from [https://catfact.ninja/fact](https://catfact.ninja/fact) and saves it locally into a txt file.

While simple in its domain, the project is structured using modern .NET enterprise patterns that ensure scalability and maintainability.

### Technical highlights

- Used Dependency Injection
- Used IHttpClientFactory
- Used .NET Generic Host
- Used Spectre.Console
- Automated unit testing via GitHub Actions
